# 홈페이지 관리 화면 사용법

휴대폰으로 공지사항, 비급여 가격표, 진료 시간을 직접 고칠 수 있어요.

## 1. 들어가기

1. 휴대폰 인터넷 창에 **홈페이지 주소 뒤에 `/admin`** 을 붙여서 들어가요.
   (예: `홈페이지주소/admin`)
2. **비밀번호**를 넣고 **들어가기**를 눌러요.
3. 한 번 들어가면 **30일 동안** 다시 비밀번호를 안 넣어도 돼요.

> 자주 쓰신다면 이 화면을 휴대폰 홈 화면에 추가해 두세요.
> 다른 사람 휴대폰에서 들어갔다면 다 쓰고 오른쪽 위 **로그아웃**을 눌러 주세요.

화면 위에 **공지사항 / 가격표 / 진료 시간** 버튼이 있어요. 고칠 것을 눌러요.

## 2. 공지 쓰기

1. **공지사항**을 누르고 **새 공지 쓰기**를 눌러요.
2. **제목**을 써요.
3. **날짜**는 오늘로 들어가 있어요. 바꾸려면 눌러서 골라요.
4. 맨 위에 계속 보이게 하려면 **맨 위에 고정**에 체크해요.
5. **내용**을 써요.
   - 빈 줄을 한 줄 넣으면 문단이 나뉘어요.
   - `1. `, `2. ` 처럼 숫자와 점으로 시작하는 줄을 이어 쓰면 번호 목록이 돼요.
   - 사진은 못 올려요. 글자만 돼요.
6. **저장**을 눌러요.

**올리면 안 되는 것:** 치료 후기, 전후 사진, 할인 이벤트

### 공지 고치기 / 지우기

- 공지사항 목록에서 고칠 공지를 눌러요.
- 고친 다음 **저장**을 눌러요.
- 지우려면 **지우기**를 누르고, 한 번 더 물어보면 **확인**을 눌러요. 지운 공지는 되돌릴 수 없어요.
- “시술 후 주의사항” 공지를 지우면 진료과목 페이지의 **시술 후 주의사항 보기** 버튼도 함께 사라져요.

## 3. 가격 고치기

1. **가격표**를 눌러요.
2. 고칠 칸을 눌러서 바꿔요.
   - **묶음 이름**: 표 왼쪽 굵은 글씨 (예: 보톡스)
   - **항목 이름**: 가운데 글씨 (예: 이마)
   - **작은 설명**: 이름 밑에 작게 나오는 글씨. 없으면 비워 두세요.
   - **가격**: 예) `100,000원`, `최대 50,000원`, `200,000~300,000원`
3. 줄을 늘리려면 **+ 줄 추가**, 순서를 바꾸려면 **▲ 위로 / ▼ 아래로**, 줄을 없애려면 **지우기**를 눌러요.
4. 새 시술 묶음은 맨 아래 **+ 새 묶음 추가**를 눌러요.
5. 표 아래 안내 문구는 맨 아래 칸에 **한 줄에 하나씩** 써요.
6. 다 고쳤으면 **가격표 저장**을 눌러요.
   가격표 위의 “○년 ○월 기준”은 저장한 달로 저절로 바뀌어요.

## 4. 진료 시간 바꾸기

1. **진료 시간**을 눌러요.
2. 시간 칸을 눌러서 골라요. 왼쪽이 시작, 오른쪽이 끝나는 시간이에요.
   - 평일 진료, 평일 점심시간, 토요일 진료
   - 쉬는 날 (예: `일요일·공휴일`), 덧붙일 말 (예: `임시공휴일 포함`)
   - 접수 마감: 진료 끝나기 몇 분 전인지 숫자로
   - 피부 시술 예약 시간 (평일, 토요일)
3. **진료 시간 저장**을 눌러요.

저장하면 첫 화면, 진료시간 표, 자주 묻는 질문, 오시는 길, 전화 창의 시간이 **모두 함께** 바뀌어요.
공지 글 안에 직접 쓴 시간은 그 공지에서 따로 고쳐 주세요.

## 5. 저장한 다음

- 화면 아래에 **“홈페이지에 반영 중이에요 (1분쯤)”** 가 나와요. 기다려 주세요.
- **“반영됐어요”** 로 바뀌면 끝이에요. **홈페이지 보기**를 누르면 확인할 수 있어요.
- 노란 창에 **“의료광고 규정상 쓰면 안 되는 말일 수 있어요”** 가 뜨면, 되도록 **고치러 가기**를 눌러 그 말을 빼 주세요.
- 저장하지 않고 다른 버튼을 누르거나 창을 닫으려 하면 한 번 더 물어봐요.

## 이럴 땐

| 이런 말이 나오면 | 이렇게 해 주세요 |
|---|---|
| 비밀번호가 맞지 않아요 | 비밀번호를 다시 넣어 주세요 |
| 로그인이 풀렸어요 | 비밀번호를 다시 넣고 들어가 주세요 |
| 다른 곳에서 먼저 저장한 내용이 있어요 | 화면을 새로고침한 뒤 다시 고쳐 주세요 |
| 반영이 늦어지고 있어요 | 몇 분 뒤 홈페이지를 확인하고, 그래도 그대로면 연락 주세요 |
| 아직 설정 중이에요 | 아직 준비가 덜 된 거예요. 연락 주세요 |
